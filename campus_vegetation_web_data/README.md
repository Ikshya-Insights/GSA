# Campus Vegetation Web Data

These GeoJSON files are copies prepared for browser mapping.

- `plants.geojson`: WGS84 longitude/latitude
- `trees.geojson`: reprojected from EPSG:3857 to WGS84 longitude/latitude
- `turf.geojson`: WGS84 longitude/latitude
- `parcel.geojson`: WGS84 longitude/latitude

Original source files were not modified.
